# Tracker metrics frontend contract

All metrics are same-origin: `/api/metrics/*`; never call the Lume deployment or send/store provider tokens or HTTP Basic credentials in JavaScript/localStorage. The backend embeds the production Lume engine with its own private encrypted data directory. Metrics always fail closed (503) until server-side METRICS_USERNAME and METRICS_PASSWORD are configured. When METRICS_ENABLED=true or any metrics credential/provider/store setting is present, the entire origin (root HTML, assets, legacy APIs and callbacks) uses the same fail-closed Basic gate. HTTP Basic uses the browser's native HTTPS credential prompt: navigate `/auth/login` to authenticate, then return `/`. API 401 means authentication required; do not offer a provider-token input.

- GET `/api/metrics/config`: configured, providers.instagram/facebook.{configured,missingConfiguration}, connected, accountCount, sessionOwnership=personal, storageAvailable; names only, never secrets.
- GET `/api/metrics/accounts`: `{accounts:[{id,provider,providerId,accountType,username,name,followers,following,mediaCount,status,lastSynced,tokenLifetime,connectedAt,expiresAt}]}`. Instagram IDs numeric; Facebook `facebook:<page-id>`.
- GET `/api/metrics/dashboard?provider=instagram|facebook|all&account=all|<id>&days=1|7|30|90`: native Lume `{mode,connected,accounts,selectedAccountIds,metrics,accountMetrics,content,series,errors,range,lastSynced,partial,stale,truncated,refreshAttemptedAt,source,message}`. `days=1` is yesterday (completed UTC day), NOT today. Metrics followers/reach/views/interactions/engagementRate are numbers OR null. Content uses id, accountId, account, caption, type, date, timestamp, url, thumbnail, reach/views/likes/comments/saved/shares/interactions/engagementRate. Lifetime metrics of posts created in range, not period engagement. Do not sum independent unique reach. Empty real data is never demo.
- POST `/api/metrics/sync` with same filters: force refresh, same response. 30-second cooldown returns 429. Same-origin browser fetch automatically includes required Origin; scripts must explicitly supply configured PUBLIC_BASE_URL.
- GET `/api/metrics/today-views?provider=instagram|facebook|all&account=all|<id>[&refresh=1]`: native Lume today payload (see `lib/backend/today-views.mjs`), UTC requestedRange and cached range, selectedAccountIds, accounts, accountViews (per-account views/range/checkedAt/error), metrics.views, knownSubtotal, availableAccounts, selectedAccounts, partial, providerDelayHours; only verified intraday totals may be displayed, otherwise null with reason. Meta daily buckets are NOT evidence of today's views.
- GET `/api/metrics/media-details?account=<id>&media=<id>`: native Lume advanced details, requires authorized account AND cached dashboard media membership. Facebook returns 422 unsupported. Null does not mean zero; no organic video-view country breakdown or retention curve is fabricated.
- GET `/api/metrics/diagnostics`: sanitized lastOAuthError.
- Navigate `/api/metrics/auth/start?provider=instagram|facebook` (alias `/auth/start?provider=...`) for official OAuth. Callbacks `/auth/instagram/callback` and `/auth/facebook/callback`, redirect back `/?connected=1` or `/?error=<safe-code>`.
- POST `/api/metrics/disconnect?account=<id|all>` (alias `/auth/disconnect`): `{ok:true,connected}`; same-origin CSRF enforced. Disconnect is local deletion, not remote permissions revocation. Prefer specific account IDs: `all` disconnects ALL providers.

All responses are no-store. Preserve errors, partial/stale and original lastSynced. Cache frontend responses only in memory, keyed by provider/account/days/UTC day/connection generation, with expiry; clear on auth failure/disconnect/reconnection. Disable CSV for stale/partial/failed data. CSV is frontend export of the returned content, not a separate provider endpoint. Do not show unsupported metrics as zero. Whole-origin authentication protects legacy APIs too when metrics are enabled/configured; other-platform tracker routes remain compatible after authentication. Every state-changing legacy request also requires Origin exactly equal to PUBLIC_BASE_URL (missing/cross-origin: 403). Cookies are write-only; account/fetch JSON never returns credential fields. Legacy Instagram collection returns 410 use_metrics_oauth; old plaintext Graph tokens are never consumed.
